# 我们一起走过：文章录入

主名称：我们一起走过。首页署名：HOPE学堂与职校生 · 2016—2026。

七个栏目：为什么是职校生；我们做过的探索；他们的十年—学生；他们的十年—老师；伙伴；前瞻思考：我们如何一起面对未来；十年档案。

管理入口仍为 admin/，连接方式不变。选择栏目，可选方向，填写标题，将完整文章放入“完整正文”框。段落间空一行，小标题可写成“## 小标题”或“### 小标题”。不需要固定章节。摘要、主题、日期、方向都是可选的。

探索的方向是学生心理健康、职涯探索、行动支持、教师支持、公众对话。公众对话包括《影子》戏剧和线上沙龙。前瞻思考的方向是“十年之后，问题变了”和“未来会发生什么”。

保存草稿或发布，操作与此前相同。已有文章、封面、附件和链接保留。旧 chapters 格式仍可阅读，新增文章使用一个完整 body 字段。旧的五条占位记录保留为草稿线索，避免读者把它们误认为完整文章。

原 history 页面留在十年档案的历史入口中；questions 的旧页面保留，并提示前往前瞻思考。旧文章链接仍可使用。
