# 材料管理

入口：网站地址后加 admin/。网站页脚也有“材料管理”。

第一次需要自己在 GitHub 创建 Fine-grained personal access token，限定 youth-from-vocational-schools 仓库，Contents 权限为 Read and write。管理页面提供具体步骤和设置链接。授权码仅在当前页面内存中使用，不写入仓库、不使用浏览器持久存储。刷新、关闭或断开后需要重新填写。

连接后点击“新增材料”，选择七个栏目之一，填写标题、摘要、正文。可选择封面与附件。单个文件最多 10 MB，视频使用外部链接。

点击“保存草稿”将资料写入仓库；草稿不会显示在网站，但公开仓库中的文件仍然可见，不能用于保存私密材料。

点击“发布到网站”提交资料和附件，GitHub Pages 随后更新。现有材料可选中编辑并再次发布；点击“保存草稿”也可将已发布材料撤回网站列表。

图片和附件与资料记录通过一次提交保存；遇到冲突不会强制覆盖，表单内容保留。移除附件只移除页面链接，不删除仓库里的文件。

自动详情页使用纯文字段落。已有模板示例不是完整案例；不填正文时不能发布为完整材料。旧 HTML 内容与页面结构继续保留，新材料自动出现在所属栏目和首页新增材料区。

本版采用授权码连接，尚未提供 GitHub OAuth 一键登录。连接真实账号及首次发布需要用户在浏览器完成验证。
