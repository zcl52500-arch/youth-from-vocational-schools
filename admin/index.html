首次使用：如何取得授权码
  1. 打开 GitHub 授权码设置，必要时登录。
  2. Resource owner 选择 zcl52500-arch；Repository access 选择 Only select repositories，勾选 youth-from-vocational-schools。
  3. Repository permissions 中 Contents 设为 Read and write。设置有效期，点击 Generate token。
  4. 复制生成的授权码，回到此页粘贴并连接。它不是你的 GitHub 登录密码。
